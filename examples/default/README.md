# Example for `button` component

## What it does

This example initializes two buttons and sets up a handler for them.

## Wiring

| Name | Description | Defaults |
|------|-------------|----------|
| `CONFIG_EXAMPLE_BUTTON1_GPIO` | GPIO number connected to the first button | "16" for `esp32`, `esp32s2`, and `esp32s3`, "6" for `esp32c2`, `esp32c3`, `esp32c5`, `esp32c6`, and `esp32c61`, "4" for `esp32h2`, and `esp32p4` |
| `CONFIG_EXAMPLE_BUTTON2_GPIO` | GPIO number connected to the second button | "17" for `esp32`, `esp32s2`, and `esp32s3`, "5" for `esp32c2`, `esp32c3`, `esp32c5`, `esp32c6`, and `esp32c61`, "3" for `esp32h2`, and `esp32p4` |
